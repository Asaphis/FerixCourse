# Hero images — how to add yours

The landing hero has 4 small image slots. To fill them, drop files here:

| Slot file      | Label shown on site |
|----------------|---------------------|
| `hero-1.jpg`   | Live classroom      |
| `hero-2.jpg`   | Students building   |
| `hero-3.jpg`   | Mentor session      |
| `hero-4.jpg`   | Project showcase    |

Rules:
- JPG or PNG both work (keep the exact filename, e.g. `hero-1.jpg`).
- Recommended size: 800 × 600 (4:3). Anything close is fine — images crop to fit.
- Until you add a file, that slot shows a neat placeholder (never a broken image).
- Restart is not needed — just refresh the page.

Tip: real photos of classes, students and projects convert far better than stock.
